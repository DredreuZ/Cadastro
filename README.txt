RETIRADA DE ESTOQUE - VERSÃO 1

Arquivos:
- index.html: aplicativo principal
- manifest.json: instalação como PWA
- sw.js: cache básico do PWA

COMO TESTAR:
1. Extraia o ZIP.
2. Para testar a câmera, o navegador normalmente exige HTTPS ou localhost.
3. Uma opção simples no computador é abrir um servidor local (ex.: VS Code Live Server).
4. No celular, publique os arquivos em um servidor HTTPS e abra o endereço.
5. O botão "Ler código" tenta usar a câmera traseira.
6. A pesquisa automática usa a API pública do Open Food Facts quando disponível.
7. PDF, CSV e TXT são gerados no navegador.

OBSERVAÇÃO:
A pesquisa na internet não garante todos os produtos. Quando não houver resultado, o código continua podendo ser cadastrado manualmente.
